העלאה ל־GitHub Pages (חינם, כ־5 דקות)
1. היכנס ל־github.com, צור repository חדש בשם f16-sim (Public).
2. לחץ "uploading an existing file" וגרור פנימה את כל הקבצים מהתיקייה (index.html, sw.js, manifest.webmanifest וקבצי ה־png). לחץ Commit.
3. Settings ← Pages ← Source: "Deploy from a branch" ← Branch: main, תיקייה: /(root) ← Save.
4. אחרי דקה הכתובת תהיה: https://<שם-המשתמש>.github.io/f16-sim/

התקנה
- מחשב (כרום/אדג'): סמל ההתקנה בשורת הכתובת, או תפריט ← "התקן את F-16 סים".
- אנדרואיד (כרום): תפריט ← "התקן אפליקציה".
- אייפון (Safari): שתף ← "הוסף למסך הבית".

הערות
- חובה HTTPS (GitHub Pages נותן אוטומטית). בפתיחה מקובץ מקומי האפליקציה עובדת, אבל בלי התקנה.
- אחרי עדכון קובץ ה־HTML: העלה מחדש ושנה ב־sw.js את VER ל־f16-v2 כדי שהמכשירים יתעדכנו.
- three.js נשמר במטמון אחרי הטעינה הראשונה, כך שהאפליקציה עולה גם בלי אינטרנט. מפה ותמונות לוויין נטענים מהרשת, ואריחים שכבר ראית נשמרים.
